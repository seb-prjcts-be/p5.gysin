01 · JavaScript colours

Canvas style

A hex colour changes the screen image. It does not create an SVG layer or choose a physical pen.

Distinction appearance first, export structure later

PAPER belongs to the canvas background. INK and RED become visible strokes.

Start

Three JavaScript strings.

Build

Use them in background and stroke.

Result

A paper, black and red preview.

In the poster

Only drawn traces can be plotted.

  1. #f0efe9 paper
  2. #151515 canvas ink
  3. #c0392b canvas red
const PAPER = "#f0efe9";
const INK = "#151515";
const RED = "#c0392b";

function draw() {
  background(PAPER); // canvas only
  plot.draw();
}
