02 · rect()

The frames

Three open frames hold the word, the return and the field.

// three open frames from the whole sheet
plot.rect(80, -70, 544, 170, {
  fray: 0.3,
  dropout: 0.14
});
plot.rect(80, 90, 544, 260, {
  fray: 0.3,
  dropout: 0.14
});
plot.rect(80, 500, 544, 360, {
  fray: 0.3,
  dropout: 0.14
});
03 · line() · circle() · path()

Scraps

Strips, patches, rings and free clippings: material before language.

// loose material from the same sheet
plot.line(82, 582, 632, 582, {
  dropout: 0.2,
  rubout: 0.18
});
plot.circle(256, 337, 450, {
  stroke: RED,
  repeat: 3,
  rubout: 0.2
});
plot.path([[80, 500], [256, 474], [624, 500]], {
  breathe: 1.0
});

05 · textCutup()

Horizontal slices

textCutup() shifts horizontal contour bands. Use it as a rare surface disturbance, not as the cut-up itself.

plot.textCutup("REMEMBERS", 60, 280, {
  size: 72,
  slices: 5,
  sliceOffset: 12
});
06 · chant()

Arrange

A phrase changes order. The lines stay clear enough to hear the change.

// the phrase returns through its orders
plot.chant("CUT TURN RETURN", 60, 90);
07 · letters() · glyphJitter

The letter field

letters() returns the sheet’s own phrase as a field.

plot.letters("REMEMBERS", 60, 60, 680, 520, {
  size: 16,
  glyphJitter: 0.7,
  breathe: 0.5,
  dropout: 0.05
});
08 · direction · the turned sheet

The turn

A line crosses columns. The sheet holds both directions.

// the row: a typed line, left to right
plot.underwood("cut the word / turn the sheet / return", 60, 320, {
  size: 22
});

// the turn: the word written downwards, over the row
const word = "WRITE";
for (let i = 0; i < word.length; i++) {
  plot.text(word[i], 620, 80 + i * 68, {
    size: 44,
    breathe: 0.9
  });
}
09 · symbols()

The mark field

symbols() fills a strip from a short alphabet of marks.

plot.symbols(60, 120, 680, 300, {
  set: '/"()-:',
  cluster: true,
  size: 16
});

Marks like + # & are not in the built-in vector alphabet. Type those with underwood() (its face has them) or pass an outline font.

10 · underwood()

The typed voice

A fixed-pitch, single-stroke label under the image.

// needs p5.gysin.underwood.min.js loaded
plot.underwood("BRION GYSIN", 60, 90, {
  size: 30,
  underline: 1
});
plot.underwood("OBSERVE / CONTINUE", 60, 170, {
  bold: true
});
plot.underwood("write / cut / turn / return", 60, 230);
plot.underwood("* * * * * * * *", 60, 290);

11 · bleed · repeat

Return & ink

The red ring returns three times. A physical pen decides how dark that becomes.

// one red ring, physically repeated
plot.circle(256, 337, 450, {
  stroke: RED,
  layer: "red",
  repeat: 3,
  rubout: 0.2
});

12 · asemic()

The margin hand

asemic() places script-shaped marks without language.

// four red gestures return in the lower margin
for (let i = 0; i < 4; i++) {
  plot.asemic(160 * i, 690, 150, 210, {
    stroke: RED,
    layer: "red",
    breathe: 1.4
  });
}
14 · layer · penMap · export

Pens & paper

Black is pen 1. Red is pen 2. The SVG leaves as numbered Inkscape layers on A4, A3 or A2.

plot.rect(80, 90, 544, 260, {
  layer: "black",
  breathe: 0.9,
  overshoot: 6,
  bleed: 0.25
});
plot.underwood("REMEMBERS", 82, 360, {
  size: 50,
  stroke: RED,
  layer: "red"
});
plot.asemic(120, 380, 240, 120, {
  stroke: RED,
  breathe: 1.4,
  dropout: 0.05,
  layer: "red"
});

const page = {
  width: 210,
  height: 297,
  units: "mm",
  margin: 10,
  scale: 200 / 720
};
plot.downloadPlotterSVG("gysin-remembers.svg", {
  page,
  penMap: { black: 1, red: 2 }
});
console.log(plot.stats({ page }));
