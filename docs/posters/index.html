Transcript

A voice message that gets harder to hear. A loop runs straight through the lines.

loads p5.gysin.min.js + p5.gysin.underwood.min.js

const plot = new GysinPlot({ seed: 612 });

lines.forEach((line, i) => {   // each line a little harder to hear
  const k = i / (lines.length - 1);
  plot.text(line, 170, 295 + i * 56, {
    size: 15,
    dropout: k * 0.32,
    rubout: k * 0.22,
    glyphJitter: 0.35 + k * 0.9
  });
});

plot.draw();

42 days

Six weeks of rainfall, one cell per day. The wetter the day, the denser the hatching.

loads p5.gysin.min.js + p5.gysin.underwood.min.js

const plot = new GysinPlot({ seed: 42 });

// rain is hatching: the wetter the day, the denser the lines
plot.rect(x, y, 72, 72, {
  fill: "hatch",
  hatchSpacing: Math.max(1.1, 9 - mm * 0.72)
});
plot.circle(x + 42, y + 42, 5);   // a dry day is a dot

plot.draw();

  size: 26,
