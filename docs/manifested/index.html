Manifested

Finished posters to look at, borrow from and start from. Open a sheet to redraw it with another seed, read the code behind it, or take its file to a pen.

Plot it

Save the plotter SVG. One Inkscape layer per pen, numbered like the pens, centre lines on an A3 sheet. In Inkscape show layer 1, load pen 1 and plot; hide it and repeat for 2.

Test it first. vanilla.penplotter plans the route here in your browser: pens, travel and time. Nothing is sent to a machine.

To plot for real, open the drawing in vanilla.penplotter: park the carriage in the home corner, use Chrome or Edge, and click to start.
