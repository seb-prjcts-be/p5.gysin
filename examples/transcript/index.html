A voice message that gets harder to hear. A loop runs straight through the lines.

The shared composition
const plot = new GysinPlot({ seed: 612 });

lines.forEach((line, i) => {   // each line a little harder to hear
  const k = i / (lines.length - 1);
  plot.text(line, 170, 295 + i * 56, {
    size: 15,
    dropout: k * 0.32,
    rubout: k * 0.22,
    glyphJitter: 0.35 + k * 0.9
  });
});

plot.draw();
