textCutup() + letter field

Gysin Demo

A typographic poster: rubbed titles, ruled band, decaying letter field.

Core snippet
// A clean title.
const plot = new GysinPlot({ seed: 19600319 });
plot.text("RUB OUT", 75, 145);   // clean, mechanical text
plot.draw();

// Two titles, rubbed away letter by letter.
titleId = plot.text("RUB OUT",  75, 145, { size: 96, rubout: ruboutAt(145), glyphJitter: letterJitter });
plot.text("THE WORD", 76, 235, { size: 96, rubout: ruboutAt(235), glyphJitter: letterJitter });

// A line sliced and re-offset.
plot.textCutup("I THINK THEREFORE I AM", 76, 370, { size: 55, slices: 9, sliceOffset: 24 });

// Six rules fan and taper.
for (let i = 0; i < 6; i++) plot.line(80 + i * 8, 448 + i * 18, 820, 448 + i * 23, { dropout: 0.04 + i * 0.03 });

// A decaying letter field.
plot.letters("RUB OUT THE WORD", 90, 600, 720, 300, { size: 26, rubout: ruboutAt(700) });

plot.freeze(titleId); // reroll leaves the top title untouched
plot.draw();

rubout 0.14 · glyphJitter 0.40

The sliders change rubout and letter drift. R rerolls the unfrozen traces; S, J and H export SVG, JSON and HPGL.
