Say It Again

One phrase, turned twice across the sheet. The pattern matters more than the words.

The shared composition
const plot = new GysinPlot({ seed: 90 });

plot.lattice("SAY IT AGAIN ".repeat(3), 48, 48, 624, 700, {
  size: 26,
  turns: [0, 90]
});
plot.lattice("SAY IT AGAIN ".repeat(3), 84, 84, 552, 628, {
  size: 26,
  turns: [45, 135],
  wear: 1.6
});

plot.draw();
