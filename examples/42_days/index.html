42 Days

Six weeks of rainfall, one cell per day. The wetter the day, the denser the hatching.

The shared composition
const plot = new GysinPlot({ seed: 42 });

// rain is hatching: the wetter the day, the denser the lines
plot.rect(x, y, 72, 72, {
  fill: "hatch",
  hatchSpacing: Math.max(1.1, 9 - mm * 0.72)
});
plot.circle(x + 42, y + 42, 5);   // a dry day is a dot

plot.draw();
