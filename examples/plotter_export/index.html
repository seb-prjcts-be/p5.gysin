Plotter Export

Build the poster once. Then describe which marks belong together and choose the physical paper only when you export.

1 · Canvas style

PAPER, INK, and RED are JavaScript colour values. They control what you see on the canvas. A colour does not create an SVG layer.

const PAPER = "#f0efe9";
const INK = "#151515";
const RED = "#c0392b";

const plot = new GysinPlot({
  seed: 19600319,
  width: 720,
  height: 900,
  style: { stroke: INK },
  export: { layer: "black" }
});

function draw() {
  background(PAPER); // canvas only; not a plotted path
  plot.draw();
}
2 · SVG layers

The constructor puts every mark in the black layer. A red mark needs two explicit choices: stroke for its visible colour and layer for its SVG group.

// Uses the black canvas ink and black SVG layer.
plot.rect(80, 90, 544, 260);

// Visible in red; grouped in the red SVG layer.
plot.circle(256, 337, 450, {
  stroke: RED,
  layer: "red",
  repeat: 3,
  rubout: 0.2,
  alpha: 0.7
});

alpha and strokeWeight can shape the canvas preview. Plotter-safe SVG uses centre lines: the installed pen determines the physical colour and line width.

3 · Physical pens

penMap assigns each SVG layer to a pen number. It does not recolour the canvas and it does not install a pen for you.

const penMap = {
  black: 1,
  red: 2
};
4 · A5, A4, A3, or A2

There is no separate A4() function. page: "A4" selects a built-in ISO export preset: exact millimetres, a 10 mm margin, top-left placement, clipping, and width-fitting scale. It changes the SVG page, not the 720 × 900 canvas composition.

plot.downloadPlotterSVG("poster.svg", {
  page: "A4",
  penMap
});
